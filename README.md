# Sara Estiri — Personal Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript.

Designed with a dark premium aesthetic, glassmorphism UI, subtle animations, and a fully responsive RTL layout.

## ✨ Features

- Dark premium glassmorphism design
- Responsive RTL layout
- Interactive floating glass sidebar
- Animated hero section
- Personal About & Experience sections
- Featured project showcase
- Text Analyzer Pro presentation
- Scroll reveal animations
- Mouse-following cursor glow
- 3D card interactions
- Mobile-friendly design

## 🛠 Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts — Vazirmatn
